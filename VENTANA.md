# Cómo cambiar la fotografía de la ventana

La web muestra automáticamente la fotografía original más reciente del ítem:

https://archive.org/details/ugju-radio-window

Para cambiarla:

1. Abrir ese enlace e iniciar sesión en Internet Archive.
2. Pulsar `Edit`.
3. Abrir `Change the files`.
4. Añadir la nueva fotografía con `Add a file`.
5. Pulsar `Save Changes` y esperar a que Internet Archive la procese.

Usar archivos `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` o `.avif`. La orientación
puede ser vertical u horizontal. No hay que modificar la web ni usar GitHub
Desktop. Las fotografías anteriores pueden permanecer en el ítem: la web elige
la original que tenga la fecha de subida más reciente.

Si Internet Archive no responde o la nueva imagen todavía se está procesando,
la web conserva como respaldo `images/window-exhibit.jpg`.
